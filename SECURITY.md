# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| < 1.2   | :x:                |

## Reporting a Vulnerability

We take the security and integrity of Dopamine and our users seriously. If you discover a security vulnerability or potential exploit, please do **NOT** open a public issue.

Please report vulnerabilities privately via:
* **GitHub Private Vulnerability Reporting**: [Submit Report](https://github.com/UniversalSDK/Dopamine/security/advisories/new)
* **Email**: `security@33rd.pro` / `support@33rd.pro`

We review security reports promptly (typically within 24 hours) and will coordinate fixes and public advisories in a timely manner.
